# Security reporting

Please report suspected vulnerabilities privately through the
[GitHub Security Advisories page](https://github.com/BenediktSchackenberg/octofleet/security/advisories)
using **Report a vulnerability**. Do not include exploit details, credentials, or
sensitive logs in a public issue or pull request.

When reporting, include the affected version or commit, steps to reproduce,
the expected impact, and a suggested fix if you have one. We will use the
private report to coordinate investigation and disclosure with you.
